# Local test database for the browser tests

`supabase/` here is a **local** Supabase project used only by `tests/e2e`,
on a laptop (`npm run test:e2e:local-db`, needs Docker) and in CI (the `e2e`
job). It is never linked to the production project.

- `supabase/config.toml` — local services; auth site URL is
  `http://localhost:3100`, where `scripts/ci/run-e2e.mjs` serves the app.
- `supabase/migrations/` — generated by `scripts/ci/e2e-db.sh` and ignored by
  git: the production baseline (with three platform-only edits, explained in
  the script) and `supabase/platform.sql`.
- `supabase/seed.sql` — the fixtures: three accounts (member with the pass,
  admin, and one only for signing out) and a small catalogue. The accounts are
  named in `tests/e2e/fixtures.ts`.

Stop it with `npm run test:e2e:db:stop`.
